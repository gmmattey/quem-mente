# desenharExperiencia

Procedimento do **Giam**.

Para cada mudança, defina:

1. fase de entrada;
2. informação que o jogador pode ver;
3. protagonista da tela;
4. ação principal;
5. feedback imediato;
6. sucesso e próxima fase;
7. erro/timeout/desconexão;
8. o que continua secreto.

Fontes: `docs/documentacao-funcional.md` e `docs/jornada-ux-ui.md`.

Uma fase deve ter uma tensão principal: papel, pista, discussão, voto ou revelação. Não transforme a rodada em coleção de cards/menus. A interface sai da frente para a conversa acontecer.
