# criarComponenteUI

Procedimento do **Guinho**.

Antes de codar, localizar UX, spec visual e protótipo aprovado. Implementar estados reais, loading/erro/timeout, teclado, safe area, acessibilidade e redução de movimento.

Não reescrever copy, criar feature ou “embelezar” lacuna com cards/gradientes. Lacuna visual relevante volta ao Giam.

Segredo, papel, pista e voto devem aparecer apenas na fase e para o jogador permitidos. A UI não é camada de segurança: autorização continua no backend.
